# 普通用户使用指南

## 这是什么

`Manga Auto Colorizer` 是一个 Windows 本地漫画阅读和自动上色工具。

它的核心特点：

- 漫画文件留在本机。
- 上色结果保存在本机。
- 不上传到云端。
- 支持按双页跨页上色，也支持批量上色。
- 可以导出完整 PDF。

## 第一次使用

1. 启动 `Manga Auto Colorizer`。
2. 进入「书库」。
3. 导入图片文件夹、PDF 或 CBZ。
4. 点击「继续阅读」进入阅读器。
5. 在阅读器里按双页查看黑白原图和彩色结果。

## 上色

阅读器里有三种常用方式：

- `上色当前跨页`：处理当前显示的两页，最后一页不足两页时只处理一页。
- `上色后 3 组跨页`：提交当前页开始的后续跨页任务，已有彩色缓存的页会自动跳过。
- `整本上色`：提交整本书的上色任务，已上色页不会重复计算。

上色不是导出 PDF 时才发生。必须先上色，才会有彩图缓存。

## 导出完整 PDF

点击 `导出完整 PDF` 后，应用会生成：

```text
library/books/<book_id>/export/colorized_book.pdf
```

导出规则：

- 已上色页使用彩色结果。
- 未上色页自动使用黑白原图补齐。
- 如果一本书没有任何彩页，导出的 PDF 会是全黑白。

## 图库

「图库」可以查看：

- 临时彩图。
- 书库彩页。

图库默认分页显示，每页 24 张，可以切换到 12、48 或 96 张。

## 反馈 Bug

如果遇到问题：

1. 打开应用里的「记录」页面。
2. 复制错误记录或阅读记录。
3. 打开 GitHub Issues：
   https://github.com/honsoncn-stack/Manga-Colorizer-/issues
4. 使用 `Bug 反馈` 模板提交。

请不要上传受版权保护的漫画原图、整本 PDF、模型权重或个人隐私文件。
