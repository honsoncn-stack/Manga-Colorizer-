# 反馈与 2.0 路线

## Bug 反馈

GitHub Issues 是当前项目的公开反馈窗口：

https://github.com/honsoncn-stack/Manga-Colorizer-/issues

反馈时请尽量包含：

- 应用版本。
- 问题出现在哪个页面。
- 复现步骤。
- 期望结果。
- 实际结果。
- 应用「记录」页面里的错误记录。

请不要上传受版权保护的漫画原图、整本 PDF、模型权重或个人隐私文件。

## 1.0 修复优先级

优先修：

1. 无法启动。
2. 无法导入。
3. 无法上色。
4. PDF 导出错误。
5. 图片闪烁、卡顿、页面滚动冲突。
6. 用户容易误解的文案。

## 2.0 计划方向

2.0 会基于 1.0 的真实反馈继续开发，重点方向：

- 更完整的产品化 UI。
- 更清楚的新手引导。
- 更强的 Gallery 大图性能。
- 更稳定的任务队列。
- 更好的批量上色控制。
- 更完善的安装包和更新流程。
- 更细的错误提示和自动诊断。

暂不承诺：

- reference 模式。
- MangaNinjia 接入。
- ComfyUI_MangaNinjia 接入。
- 浏览器插件。
- 云端上传。

如果喜欢这个项目，欢迎在 GitHub 上点 Star。
