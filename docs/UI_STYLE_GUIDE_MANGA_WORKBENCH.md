# UI Style Guide: 日漫漫画工作台风

## 风格名

日漫漫画工作台风

## 核心颜色

- Ink Black: `#101018`
- Deep Navy: `#171A2E`
- Paper White: `#F8F4EA`
- Sakura Pink: `#FF6FAE`
- Cyan Blue: `#57D7FF`
- Violet: `#8C6CFF`
- Warning Yellow: `#FFD166`

## 视觉元素

- 漫画分镜边框
- halftone 网点
- 速度线
- 纸张纹理
- 胶囊状态标签
- 渐变按钮

## 页面布局规范

- 左侧固定导航
- 主内容使用分镜式卡片
- 右侧或下方日志区
- 结果使用原稿陈列网格

## 禁止项

- 不使用任何受版权保护的动漫角色
- 不使用任何官方 IP 素材
- 不使用任何品牌 Logo
- 不从外部抓取动漫插图作为背景
